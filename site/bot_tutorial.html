Техническое руководство: Telegram-бот

Введение и исследование

В рамках вариативного задания было проведено исследование предметной области «Разработка чат-ботов». Telegram-боты представляют собой удобный интерфейс для взаимодействия человека и техники. В нашем случае бот выступает пультом мониторинга состояния робота «Робокрафт».

  • Язык программирования: Python 3.10+
  • Библиотека: pyTelegramBotAPI (Telebot)

Архитектура взаимодействия

Логика работы базируется на методе Long Polling, при котором Python-приложение опрашивает серверы Telegram на наличие новых команд от пользователя, после чего взаимодействует с состоянием робота.

Пошаговая инструкция

Шаг 1: Регистрация бота

Откройте Telegram, найдите @BotFather и отправьте команду /newbot. Следуйте инструкциям для получения HTTP API Token.

Шаг 2: Установка зависимостей

Исходный код проекта лежит в папке src/ репозитория. Для начала работы установите библиотеку:

pip install -r requirements.txt

Шаг 3: Основной код бота

Пример реализации ответа на команду /status:


import telebot
bot = telebot.TeleBot('TOKEN')

robot_state = {"status": "online", "battery": 85, "speed": 0}

@bot.message_handler(commands=['status'])
def check_status(message):
    status_msg = f"Батарея: {robot_state['battery']}%\nСостояние: {robot_state['status']}"
    bot.send_message(message.chat.id, status_msg)

Модификация: Оценка пинга

В рамках творческой модификации была разработана команда /ping, которая измеряет задержку при обращении к внутренним системам робота. Это реализовано через редактирование отправленного сообщения (пользователь видит, как статус обновляется в реальном времени):


@bot.message_handler(commands=['ping'])
def ping_robot(message):
    start_time = time.time()
    msg = bot.send_message(message.chat.id, "Отправка запроса...")
    time.sleep(0.5) # Имитация работы с ESP32
    ping_time = round((time.time() - start_time) * 1000)
    bot.edit_message_text(f"✅ Ответ получен!\nЗадержка: {ping_time} мс", 
                          chat_id=message.chat.id, 
                          message_id=msg.message_id)
