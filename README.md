# Проектная практика: Робокрафт

**Группа проектов:** «Робостанция»
**Подпроект:** Робокрафт
**Куратор:** Никулина Анна Константиновна

## О проекте
Проект «Робокрафт» — это разработка и создание функциональной модели мобильного робота (робота-танка) с дистанционным управлением.
Проект включает в себя 3D-моделирование, схемотехнику (ESP32, L298N) и программирование.

## Структура репозитория
- `site/` — статический веб-сайт проекта.
- `docs/` — документация в формате Markdown (описание, журнал прогресса, отчет о взаимодействии с партнером).
- `reports/` — отчеты по проектной практике.
- `task/` — исходные материалы задания (из шаблона).

## Как открыть сайт
Перейдите в папку `site` и откройте файл `index.html` в любом современном веб-браузере.
